# 商标检索指南：App 名字定稿前必做

**背景**：候选名「打工人闹钟」要在 GitHub 公开前定稿。2024 年已有公开报道：网络热词
「打工人」被批量抢注，覆盖第 9–38 类与 42 类（「早安打工人」等变体也在其中）。
所以**不能假设这个名字干净**——定稿前必须查，查完再决定用不用。

**为什么必须查**：应用商店受理商标投诉。若「打工人」在第 9 类（可下载软件）已有有效注册，
「打工人闹钟」作为含该词的组合同样有被投诉下架的风险；GitHub 分发不受商店约束，
但名字要跟着 App 一辈子，现在花半小时，好过将来到手几千用户时被迫改名。

## 一、查什么

| 项 | 值 |
| --- | --- |
| 商标名 | 打工人闹钟、打工人、班表闹钟、打工人班表（候选全查一遍） |
| 类别 | **第 9 类**（可下载的手机应用软件，核心）+ **第 42 类**（软件设计 / SaaS 服务） |
| 类似群 | 0901（计算机软件）、4220（软件设计 / 维护） |
| 状态 | 只看「有效」的注册 / 初审公告；已注销、被驳回、期满未续展的不挡路 |
| 申请人范围 | 全部，不限地域 |

## 二、在哪查

1. **中国商标网**（sbj.cnipa.gov.cn）→ 商标网上服务系统 → 商标查询。官方数据源，需注册账号。
2. 第三方（数据同源、界面好用）：阿里云商标查询、标库网、权大师等。适合先粗筛。

## 三、怎么判断

| 查询结果 | 结论 |
| --- | --- |
| 9 类 / 42 类，0901 / 4220 类似群，无「打工人」及近似词的有效注册 | ✅ 「打工人闹钟」可用 |
| 有「打工人」注册但**不在软件类似群**（如 25 类服装、43 类餐饮） | ✅ 不挡 App，可用 |
| 9 类或 42 类软件类似群有「打工人」有效注册 | ⚠️ 「打工人闹钟」作为含词组合，注册受阻、使用有被投诉风险 → **退「班表闹钟」或「打工人班表」，同样标准再查一遍** |
| 有「打工人闹钟」完整注册 | ❌ 直接换名 |

近似判断的朴素标准：同类别 + 同类似群 + 文字构成近似（含相同显著词），即构成障碍。
「打工人」三字若在软件群被占，含它的组合名基本都会被驳。

## 四、注意

- **盲区**：已提交未公示的申请查不到。个人项目风险可接受；真要万无一失走代理所
  （约千元级，含异议 / 复审预案）。
- **注册不是必须的**：不注册也能用，风险是「别人注册后反过来告你侵权 / 商店下架」。
  个人项目可以先不注册，但**必须确认没被注册**。
- 查到冲突别慌，退路已经备好：班表闹钟、打工人班表，判断标准同上表。
