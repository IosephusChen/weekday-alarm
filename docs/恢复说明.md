## 四、签名（唯一「丢了不可挽回」的东西）

`debug.keystore` 是当前打包用的密钥：

| 项 | 值 |
| --- | --- |
| 文件 | `/workspace/debug.keystore` |
| 别名 | `androiddebugkey` |
| 密码 | `android` |
| storePassword | `android` |

这是 Android 开发机通用的公共调试密钥，**测试期够用，发布前必须换正式密钥**。

换了正式密钥后，`debug.keystore` 就变得至关重要：**一旦丢失，永远无法更新已发布的应用**，只能换包名重新上架，老用户全丢。到时候请让用户自己另存一份到手机 / 网盘。
