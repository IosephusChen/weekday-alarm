# 打工人闹钟 · 使用说明

一个只做一件事的闹钟：**按你的周休制度推算上班日，只在上班日响铃**，并把法定节假日与调休补班算进去。

双休、单休（周日休 / 周六休）、大小周都支持——不管哪种排班，都不用再手动改闹钟。

- 当前版本：**v1.50.0**
- 安装包：`打工人闹钟-v1.50.0.apk`（versionCode 151）——直接覆盖安装，不用卸载
- 旧版备份：`打工人闹钟-v1.23.9.apk`（versionCode 66），只在想退回旧版时用（退回需先卸载）
- 系统要求：Android 8.0（API 26）及以上

---

## 安装

1. 把 `打工人闹钟-v1.50.0.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 点击安装。若提示「未知来源应用」，在弹窗里允许本次安装即可。
3. 首次打开请按提示授予**通知**权限；响铃要能自动弹出界面，还需要在系统设置里为本应用开启：

**哪些必须、哪些可选**（v1.47.1 按真机测试重新定过）：

| 权限 / 设置 | 必需性 | 没有会怎样 | 位置（HyperOS） |
| --- | --- | --- | --- |
| **通知** | **必需** | 闹钟响了**没有停止按钮**，只能强行停止 App | 设置 → 通知管理 → 打工人闹钟 |
| **自启动** | **必需** | 划掉 App 后闹钟**到点不响**（排着，但广播被系统丢掉） | 设置 → 应用管理 → 打工人闹钟 → 自启动 |
| 后台弹出界面 | 建议 | 锁屏时不见整屏，解锁时也不自动弹，只能下拉通知栏停 | 应用管理 → 打工人闹钟 → 其他权限（开了会连带开启全屏通知） |
| 显示悬浮窗 | 可选 | 解锁响铃时没有小横幅，退回整屏 | 其他权限 → 显示悬浮窗 |
| 锁屏显示 | 部分机型必需 | 荣耀 / 华为 / OPPO / vivo 上锁屏只亮屏，不见响铃页 | 应用 → 权限 → 锁屏显示 |

> **不用管的两项**：省电策略 / 电池优化（闹钟走系统闹钟通道，不受省电限制）、
> 闹钟和提醒（声明了精确定时权限，安装即授予，系统里也关不掉）。两项都已从引导里删掉。
>
> **两条底线**：通知（否则关不掉）、自启动（否则不响）。
> 其余都可以不完美：只是「晚一分钟」「少一个界面」，不会变成静默失败。
> 万一真的只剩一条路，App 自己也有兜底：响铃时首页会出现「闹钟正在响 · 停止」；
> 通知关着的情况下，铃声最多响 5 分钟自动停。

## 界面结构（v1.22 起）

首次安装启动时先走 **3 步新手引导**，每步顺手把配置做掉（**从旧手机换过来的话，第 1 步右上角有「导入」**，选旧备份就不用重填；导入后会自动跳到第 3 步开权限，因为新手机还没有任何授权）：第 1 步选周休制度（点哪张存哪张），第 2 步设第一个闹钟（默认 07:30，点时间就能改；下面四行还能直接调响铃音量、渐响、稍后提醒、响铃前提醒），第 3 步过一遍权限清单（通知 / 后台弹出界面 / 自启动 / 显示悬浮窗 / 锁屏显示，能查的实时显示已开还是没开，点整行直接跳到系统页；自启动读不到状态、锁屏显示给的是「测一下」），最后可以点「试听一下响铃」当场验一次——会响一声并弹出响铃页，点「结束测试」就停，不影响正式排班。点「开始使用」就等于配好了，不用回主界面再摸一遍；半路按返回键退出的话，下次启动还会出现。之后主界面只留每天要看的东西——今日状态、闹钟列表、排班日历；其余全部收进设置页：

> 首页三块，从上到下：**今天什么情况 → 闹钟 → 本月班表**。
> 周休制度、使用说明、测试响铃、运行状态都在设置页——它们一年动不了几次，
> 占着首页就会把闹钟和日历挤出第一屏（v1.46.2 ~ v1.46.4 三刀瘦了 473dp）。

- **「今天 / 明天不上班」并排两个按钮**（v1.34.0）：今日状态卡底部一行两格。那天是上班 / 补班日，按钮写「不上班」，点一下当天全部闹钟跳过；那天是休息 / 法定假日，按钮写「要加班」，点一下当天「仅上班日」闹钟照响。再点一次撤销。**点完按钮会变成实白底 + 紫字，文案改成「今天已请假 / 今天已加班」**，和桌面小组件同一个样子，一眼看得出生效了。睡前想起来明早要请假，直接点右边「明天不上班」，不用等到第二天。
- **排班日历回到首页**（v1.34.0）：整张月历内嵌在闹钟列表下面，**默认展开**，不再需要点进去。点某一天标请假 / 加班——**上班日也能标加班**（白天上班、晚上补工），同一天两个都能标，格子上印「假加」；过去的日子也能补记（翻到那天点一下，选「标记为请假 / 加班」，格子上照样印「假」「加」；补记只作记录，不影响已经过完的那些天的闹钟），点灰字日期翻到那个月，右上角「回本月」跳回当月；格子下方是图例；标错了就点那一天，选「取消请假 / 取消加班」。
- **小组件上直接说明天不上班**（v1.31.0）：「本周班表」小组件底部多了一个按钮——明天要上班时写「明天不上班」，明天本来就休息时写「明天要加班」，点一下标记、再点一下撤销。改完立刻重排闹钟，两个小组件同步刷新，不用先打开 App。
- **小组件上也能点「今天不上班」**（v1.33.0）：「本周班表」底部并排放了「今天不上班」和「明天不上班」两个按钮——今天要上班就点左边请假，今天本来就休息就点右边改成加班。点完按钮变成实白底 + 「今天已请假 / 今天已加班」，再点一次撤销，闹钟立刻重排。
- **给闹钟上色**（v1.30.0）：编辑闹钟时下面有四个圆点（默认 / 橙 / 绿 / 紫），选完保存，列表里那条的时间大字就跟着变色。「起床」橙、「午休」绿、「吃药」紫，三条并排时一眼能认出哪条。关掉的闹钟仍是灰字——颜色说用途，灰不灰说有没有开。
- **长按一条闹钟**（v1.29.0）：弹「复制这个闹钟 / 删除这个闹钟」。复制会连时间、规则一起带过来，名称自动加「副本」——「照这条再来一个」比删除更常用，以前只能从头再填一遍。一次性闹钟复制时日期会顺延到下一个同一时刻，不会复制出一条永远不响的。
- **距下次响铃倒计时**：今日状态卡底部一行，一天以内显示「时:分:秒」，超过一天显示「N 天 时:分」（这时秒没有意义，还会让人以为马上要响）。响完自动接下一个，跨天自动重算日期与日历。一条启用的闹钟都没有时数字留「--:--:--」，副标题会写明原因。
- **一周开始日**（设置 → 更多设置 → 排班与显示）可选周一或周日：只换日历与「本周班表」小组件的列顺序，班 / 休判定和闹钟时间都不受影响。
- **周休制度**（设置 → 排班与节假日，与引导第 1 步同一套卡片）点开后先选大类——大小周 / 双休 / 单休。选「大小周」下面才展开「本周是（大周 / 小周）」和「小周休哪天」；选「单休」只展开「休哪天」（默认周日休）；选「双休」两项都不出现。确定后立刻重排，不用再找「保存」。
- 「本周是」「小周休哪天」不再各占一行，都并进上面这个对话框，只在选「大小周」时出现。
- 设置分成**主页 + 两个二级页**（v1.49.0）：主页只放高频项（音量就地拖、两个提醒直接开关、铃声、周休制度、节假日数据），其余在「更多响铃设置」与「更多设置」里。
- 每行统一「左标题 + 右值」，行间细分割线，不再有居中和左对齐混排的错位感。
- 日历图例固定 **2 行 × 4 列**，第二行空一格占位，两行的色块与文字左边缘严格对齐。
- 使用说明收成**一行入口**（v1.34.0），点进去是**使用说明页**（v1.34.2 修正）：按「排班与日历 / 闹钟 / 请假加班 / 小组件 / 设置与备份」分成五节，带着问题去查能直接扫到那一节。这一页只做手册，不再放引导入口（v1.41.0）。
- 想重看新手引导：设置 → 更多设置 → 新手引导与权限（这是唯一入口，第三页就是权限清单，重看往往是为了查权限）。改时间会直接改第一个闹钟，不会多出一个；稍后 / 响铃前提醒在这里改和设置页是同一处。
- **更新日志**：升级后第一次打开会弹一次「这一版改了什么」，点「知道了」关闭；想回看任何一版，进 设置 → 更多设置 → 更新日志。日志内置在安装包里，不联网也能看。

## 使用步骤

0. **首次打开**：走完 3 步引导（选制度 → 设第一个闹钟与响铃设置 → 开权限 → 试听一次），点「开始使用」进入主界面。点完就开始生效，没有别的开关要拨。以后可在设置页重看。
1. **选周休制度**（只在第一次需要）：引导第 1 步已经问过；之后要改，进**设置 → 排班与节假日 → 周休制度**。点开先选大类——大小周 / 双休 / 单休；选「大小周」下面才展开「本周是大周还是小周」和「小周休哪天」，选「单休」只展开「休哪天」（默认周日）。App 以「大周周六」为基准往后交替推算。
2. **添加闹钟**：点「+ 添加闹钟」，填名称（**可不填，留空就叫「闹钟」**）、选时间（自绘「时 / 分」双列滚轮）、选规则：
   - 仅上班日：只在该制度的工作日、调休补班日响（推荐，起床闹钟就用这个）
   - 每天：每天都响
   - 仅休息日：只在该制度的休息日响（双休=周六日，单休=那一个休息日；午休闹钟常用）
   - 仅一次：只在那一天响，响过自动关闭（赶车、临时开会）。日期默认**今天**，点日期可改；如果那个点今天已经过了，保存时会自动顺延到明天并提示
3. **改完就生效**：加闹钟、改时间、改规则、改排程，都会立刻重排，不用再点保存。每条闹钟右侧有自己的开关，拨一下单独停掉它。
4. **请假**：在日历里点那一天 →「标记为请假」，当天全部闹钟自动跳过；再点一次取消。过去的日子也能补记（上周三请了假，翻到那天点一下即可），补记只作记录，不影响已经过完的那些天。标错了同样点那一天取消——没有批量清除，一次删掉全部记录太容易误伤。
5. **休息日加班**：在日历里点那一天 →「标记为加班」，当天的「仅上班日」闹钟照响；再点一次取消。
6. **设置页**分四段：闹钟（音量、铃声、更多响铃设置）、排班与节假日（周休制度、节假日数据）、提醒（睡前提醒、响铃前提醒）、其他（更多设置）。一周开始日、提醒范围、节日开关、备份都在「更多设置」里。
7. **睡前提醒**（可选）：设置 → 睡前提醒 → 选 22:00 之类的时间。到点会告诉你明天要不要早起、明早几点响；通知里的「明天请假」可以一键取消明早闹钟。
8. **换手机**：设置页底部「导出配置」存成一个文件，新机装好后「导入配置」整份恢复（闹钟、排班、请假/加班标记、音量铃声全都在）。
9. **使用说明**在「设置 → 更多设置 → 使用说明」，点那一行进入说明页（分五节，随时可查）。想被带着重新设一遍，去「设置 → 更多设置 → 新手引导与权限」——说明页不再重复这个入口。

## 周休制度

**设置 → 排班与节假日 → 周休制度**，点开后是「大类 + 条件细节」（v1.46.3 从首页搬来，v1.49.2 改成分层，v1.49.5 换成与引导页同一套卡片）：

| 大类 | 选完展开的细节 | 休息日 |
| --- | --- | --- |
| 大小周 | 本周是大周还是小周；小周休哪天 | 一周双休、一周单休交替 |
| 双休 | 无 | 每周六、周日 |
| 单休 | 休哪天（周六 / 周日，默认周日） | 每周固定一天 |

- 具体日子收在条件区，大类里不掺细节：选完「单休」才问休哪天，选「双休」什么都不问。
- 三张大卡片的标题与副标题，和**新手引导第 1 步完全一样**（大小周 / 双休 / 单休），在引导里认过一次，回来改时是同一张脸。
- 换制度后立刻按新制度重排：先取消系统里已登记的旧闹钟，再按新规则重新登记，不会新旧混着响。
- 老版本升级上来**默认仍是大小周**，排班一天都不会变。
- 「仅休息日」闹钟跟着制度走：单休（周日休）时只在周日响，不会在要上班的周六早上被懒觉闹钟吵醒。

## 响铃时能做什么

**看你在干什么，决定用多大的界面叫你**（v1.45.0 定稿）：

| 手机状态 | 响铃时 | 为什么 |
| --- | --- | --- |
| 解锁使用中 | **贴顶横幅**从状态栏下面滑下来：深色半透明卡，左边大图标，中间大号响铃时刻 + 小字闹钟名，右边两个圆钮（「稍后提醒」白描边、「停止」实色紫）。点横幅空白处才进整屏 | 你正看着屏幕，横幅够用，也不挡中间的内容 |
| 锁屏 / 息屏 | **整屏响铃页** | 横幅在那时候根本没人看得见 |

这条规则改过七轮，都记在更新日志里：v1.23.1「解锁只发通知」→ 用户说响铃什么都不弹 → v1.39.0「解锁也整屏」→ 用户说太粗暴 → v1.40.0「解锁弹小窗（居中小卡片）」→ 用户说浮在屏幕中间太突兀 → v1.41.0「贴顶横幅」→ 用户说两张卡叠在一起 → v1.42.0「只留我们的横幅，系统那张不再弹」→ 用户说位置还偏下、布局要照系统闹钟 → v1.43.0「深色半透明卡 + 大号时刻 + 两个圆钮，贴到状态栏下沿」→ 用户说背景模糊把整屏都糊了、反而看不见别的内容 → v1.43.1「去掉模糊，只留半透明」→ 用户说位置还偏下 → v1.44.0「往上挪」→ v1.45.0「顶边直接写状态栏高度，不再靠系统兜」。

横幅靠「显示悬浮窗」权限，没开时会自动退回整屏，不会什么都不弹。

> 系统设置里会多一个通知渠道「响铃（屏幕亮着时）」，它的重要性是「低」——这是故意的：解锁响铃时界面已经由横幅负责，这条通知只需在通知栏里可点可停，不能再弹一张系统横幅。**别把它关掉**，关掉的话通知栏里就没有「停止」入口了（横幅还在）。

点完「稍后提醒」之后那条「5 分钟后再响」走的是独立渠道「稍后提醒」（v1.46.0 起），也是低重要性、不响不震。它以前借的是「响铃前提醒」——你嫌响铃前的预告烦把它关掉，会连带把这条也关没，而它恰恰是你最需要确认的那一条。

响铃前提醒另说：它只是「30 分钟后要响」的预告，解锁使用中是一条横幅（带「这次不响」），锁屏 / 息屏才弹整屏。

> 锁屏响铃要**先解锁**才看到界面，不是 App 的问题，是系统里的「锁屏显示」关着（荣耀 / 华为 / OPPO / vivo 都有这个开关，不在标准权限里，App 读不到）。开法见上面权限表。

- **改完就开**：编辑一条关着的闹钟并保存，会自动把它打开——调完时间就能响，不用回列表再拨一次开关。改「已经响过」的一次性闹钟时，日期会自动顺延到下一个该时刻，并当场告诉你改到了哪天。
- **一次性闹钟的日期写法**：近的说「明天 · 10月23日」，远的说「10月30日 周五」。列表里响过的写成「已响过 · 10月20日 周二」，不再挂「仅一次」——它已经响完了。
- **稍后提醒**：默认 5 分钟后再来一次、最多 3 次；间隔可选 3 / 5 / 10 / 15 / 30 分钟，次数可选 1 / 2 / 3 / 5 次或不限。点完之后通知栏会留一条「稍后再响」，写着「5 分钟后 · 07:05 再次响铃」并带倒计时，看到它就说明排上了；不想再等就点那条上的「取消」。
- **关闭**：停止本次响铃。
- **按键**：音量键 / 电源键可分别设为「稍后提醒」「关闭这次响铃」或「无」（防止误按关机键直接静音）。
- **自动停止**：响铃时长默认 10 分钟（到点自动停），可设 1 / 3 / 5 / 10 分钟或不限。
- **静音仅震动**：把闹钟音量拖到 0，并保持「响铃时震动」开启；两样都关掉就是完全安静，只在屏幕上显示。
  音量行会照实说：0 且震动开着写「静音（仅震动）」，震动也关了就写「静音（不震动）」。

## 桌面小组件

长按桌面空白处 →「小部件」→「全部应用」→ 拉到最底点「安卓小部件」→ 找「打工人闹钟」。也可以直接进 **设置 → 更多设置 → 添加到桌面**，选一个让系统放上去。

> 为什么不直接出现在小部件首页：澎湃把第三方 App 的标准小部件统一收在「安卓小部件」二级列表里，只有接入澎湃自家小部件规范的应用才进「推荐」。这层入口不是 App 能改的。

v1.50.0 起是**四个固定尺寸**的组件，按需要选，不用再拖尺寸去换布局：

| 组件 | 尺寸 | 显示内容 |
| --- | --- | --- |
| 下一个闹钟 | 4×2 | 下次响铃的日期、星期、时间、闹钟名，以及未来若干天的提醒总数 |
| 下一个闹钟和本周 | 4×4 | 上面这些，加上本周 7 个格子，以及底部「今天 / 明天不上班」两个按钮 |
| 本周班表 | 4×2 | 周一到周日 7 个格子各自的「班 / 休 / 假 / 补」，今天有高亮；请假、加班标记同步显示；底部「今天不上班 / 明天不上班」可直接点 |
| 本月班表 | 4×4 | 整月 42 格：每天的班 / 休、节日名、请假与加班角标，今天高亮；底部同样有两个请假按钮 |

四个组件的尺寸是固定的，不能拖动改大小——想要别的尺寸就换一个组件，而不是把它拉大。

主 App 里任何改动（改设置、响铃后重排、开机）都会自动刷新；另外每 30 分钟兜底刷新一次，跨天后「今天」的高亮不会停在昨天。

## 响铃前提醒

设置 → 提醒 → 响铃前提醒，默认 **提前 1 小时**，也可选 **关闭 / 5 / 10 / 15 / 30 分钟**。

到点前会提醒你，但**分两种方式**：手机解锁使用中只弹一条横幅通知，不打断你；锁屏或息屏时才弹出整屏提醒——「还有 30 分钟」「起床 · 明天 07:00 响铃」，下面两个按钮：

- **知道了**：收起弹窗，闹钟到点照常响。
- **关闭这次响铃**：取消这一次（只取消这一次，排班和其他闹钟不受影响）。

弹窗 **45 秒自动收起**；无论弹不弹窗，通知栏都留一条「即将响铃」，随时可以回去看或关掉。弹窗本身**不响铃、不震动**——声音留给真正的闹钟，不会在响铃前先吵一次。

通知栏那条写的是**绝对时间**（「14:10 响铃」），不读秒。以前它每秒跳一次，眼睛会一直往那儿瞟，比一句话更吵；而「还有多久」这个判断，看一眼现在几点就知道了。

**通知栏那条是常驻的**，跟系统自带闹钟一个脾气：

- 通知右侧直接带一个「**这次不响**」按钮，不用进 App 就能取消这一次响铃——只取消这一次，闹钟本身照旧，明天还会响。
- **锁屏卡片、下拉后未展开的卡片上都有这个按钮**。这一条是 v1.23.6 才真正做到的：锁屏和「下拉但没展开」渲染的都是通知的**折叠态**，折叠态由系统模板生成，只放小图标、标题和一行正文，`addAction` 的按钮要展开才出现——所以前几版锁屏上永远看不到按钮。现在折叠态换成了自绘布局：第一行是紫色图标 + 「午休 即将响铃」+「15:42 响铃」，第二行右侧是「这次不响」紫药丸。
- **锁屏 / 亮屏时弹出的横幅上也有这个按钮**，用的是另一套自绘布局（`setCustomHeadsUpContentView`），跟澎湃系统闹钟的做法一致。
- 下拉展开后，同一条通知里还有「这次不响」，三处都能点。
- 点通知进详情页、退出来，通知**不会消失**；只有闹钟真的响了、你点了关闭，或者主动取消这个闹钟，它才撤掉。这样睡前瞄一眼通知栏，就知道「明天这个闹钟还挂着」。
- 关掉某个闹钟（或把闹钟删到一条不剩）时，它那条「即将响铃」会一起撤掉，不会留下一条点了没反应的僵尸通知。
- 从旧版升上来的话，装完第一次打开 App 会清掉旧通知、重发一条带按钮的——旧版发的那条没有图标，按钮永远长不出来。

**如果这条通知被收进了「更多通知」**：那是澎湃的「通知过滤」干的。它按通知文本、这台手机的历史点击率、用户属性打分，分低就折叠进二级页——**App 里没有任何开关能强制某条通知「重要」**，这是服务端模型。改法两条，都在系统侧，改一次长期有效：

- 左滑那条通知 →「设为重要」。之后这个应用的通知都会保持重要，不再被折叠。
- 或者 设置 → 通知和状态栏 → 关掉「通知过滤」（全局，影响所有应用）。


**设得晚也能收到**：提前量是按「响铃时刻往回减」算的。2 点的闹钟设了提前 1 小时，只要 1 点之后、2 点之前把闹钟设好或改动设置，App 会立刻补发一次提醒（1:31 设的就 1:31 提醒，不会因为「1 点已经过了」而整个跳过）。同一条提醒只会发一次，反复改设置不会连环弹。

弹窗被系统拦下时（没给「后台弹出界面」/「全屏通知」权限），仍然会有横幅和通知栏提醒，不会漏。第一次用建议按前面「安装」那节把这两项权限开上。

> 开启响铃前提醒后，每个响铃实例会多占一个系统闹钟名额，App 会自动把主闹钟排程上限减半（200），保证不超过 ROM 的 500 硬限——代价是提醒范围末尾的几天会靠响铃后滚动补排。

## 睡前提醒

设置 → 睡前提醒，可选 **21:30 / 22:00 / 22:30 / 23:00** 或自定义时间（滚轮）。到点发一条安静的通知，不响铃不震动：

| 明天的情况 | 通知内容 | 带什么按钮 |
| --- | --- | --- |
| 要上班，有闹钟 | 「明早 07:30 起床 会响，早点睡」 | 明天请假 · 点开 App |
| 要上班，但没有一条闹钟是开的 | 「明天没有会响的闹钟，记得加一个」 | 明天请假 · 点开 App |
| 休息 / 已请假 | 「明天不用早起，闹钟不会响」 | 点开 App |

- 「明天请假」会直接把明天标为请假并取消明早的全部闹钟，省掉「打开 App → 翻日历 → 点明天」三步。这个按钮直接画在卡片的第二行，锁屏和刚弹出来时就能点，不用先展开。
- 默认只在**明天要上班**时提醒（「仅在明天上班时提醒」开关），休息日不打扰；关掉这个开关则每天都发。
- 提醒时间一到就续订下一天，长期不打开 App 也不会断。

## 节日显示

日历里日期下方的两个字，优先级从高到低：

| 顺序 | 显示 | 例子 |
| --- | --- | --- |
| 1 | 调休补班「补」 | 10 月 10 日要上班，标「补」 |
| 2 | 法定节假日名 | 10 月 1–7 日整段标「国庆」 |
| 3 | 农历节日名 | 九月初九标「重阳」 |
| 4 | 基督教节日名 | 12 月 25 日标「圣诞」 |
| 5 | 班 / 休 / 假 | 普通日子 |

**法定节假日**：元旦、春节、清明、劳动、端午、中秋、国庆。名字只标在**正日**——10 月只有 1 号写「国庆」，2–7 号写「假」；春节假期从 2 月 15 日开始，但正月初一是 2 月 17 日，所以只有 17 号写「春节」；清明标节气当日（2026 年为 4 月 5 日）。这样连着的「假」一眼能看出假期有几天，节日当天也不会被淹没。

**农历节日**：春节、元宵、端午、七夕、中秋、重阳、腊八、除夕。农历是内置的 1900–2100 年历表，纯本地计算、不联网、不需要更新。

**基督教节日**（默认关闭，含天主教与新教共同遵守的节日）：圣诞、平安、复活、受难、圣灰、圣枝、升天、五旬、主显、献主、若瑟、圣母、诸圣、无染，共 14 个。其中复活节的日期每年不同（春分后第一个满月之后的第一个星期日），由教会历法推算；圣灰、圣枝、受难、升天、五旬都由复活节前后推得。其余是公历固定日期。

底色始终表示那天上班还是休息（上班色 / 休息色 / 假日色 / 补班色），所以换成节日名不会丢信息。今日状态卡也会显示，例如「国庆 · 农历八月廿一」。不想看可在设置里分别关掉「农历节日」和「基督教节日」——两个开关互不影响，法定节假日名不受它们控制。

「补」永远优先：那天要上班，比是什么节日更要紧。

## 常见问题

**Q：闹钟不响 / 只在通知栏出现？**
检查「全屏通知」「后台弹出界面」是否开启（澎湃 OS 尤其重要），并确认省电策略为「无限制」。

**Q：重启手机后还要重新开开关吗？**
不用。开启状态下重启会自动恢复排程，无需手动重开。

**Q：明年节假日怎么办？**
节假日数据内置到 2026 年底，国务院公布新一年安排后，在设置页点「节假日数据」即可在线更新，无需升级 App。

**Q：换了时区或手动改了系统时间，闹钟还准吗？**
准。App 会监听时区与系统时间变化，收到后按新的本地时间重排全部闹钟。

**Q：点「节假日数据」提示在线检查未成功？**
说明当前网络连不上数据源（数据源在境外，弱网下容易超时）。弹窗里会给出具体原因，内置数据仍然完整可用，不影响大小周与调休推算；换到 Wi-Fi 再点「重试」即可。

**Q：为什么时间选择器不是系统的表盘？**
澎湃 OS 会无视框架 TimePicker 的主题设置、强制渲染成表盘拨轮，所以改用自绘的「时 / 分」双列滚轮，观感与系统闹钟一致。

**Q：提醒范围选 365 天，闹钟会不会太多？**
系统对单应用可注册的闹钟数量有硬上限，超出时 App 会优先排程最近的若干个，更久的会随闹钟响铃自动补上，不会漏。
