## 怎么用这张表

- 老截图、老文档、老注释里看到 `v1.xx.y` 或「versionCode 1xx」，来这里查它现在叫什么。
- `v1.23.9` 有两个 code（66 和 72）：66 是本体（现 v0.34.2 / 66），72 是同名覆盖版（现 v0.34.3 / 67）。
- 重排后 **v0.80.1 / 182 = 重排前的 v1.71.10 / 188**，是当前这一版。
- 以后新版本从 **183** 起，按规则递增；versionName 与 versionCode 从此一一对应。
