引导页加「导入旧备份」· 三种摆法

换手机时最亏的路径：装好 App → 在引导里把周休制度和闹钟重新填一遍 → 走完 3 页才发现设置里能导入。 入口该出现在「用户开始做决定」的地方，而不是「他已经做完」的地方。
另一个前提（用户 17:52 指出）：新手机装完是没有权限的，导入完直接进主界面 = 第二天不响。 所以导入后必须去第 3 页开权限——这让「导入」从「一个选项」变成「一次跳转」，摆放位置也跟着变。

怎么选

方案新增高度谁会看到代价
A 底部一行44dp（仍留 148dp）愿意扫一眼底部的人可能被完全忽略，等于没做
B 顶部右上0dp所有人在第一页就看得到第 2、3 页没有入口
两者导入后都跳到第 3 页；差别只在「入口是否会被看见、是否暗示错误的交互」——A 看着像选项，其实是跳转。
B + 第 3 页补一个0dp + 页 3 再涨两处都能进第 3 页已超 82dp，再塞更难看见；且违反「同一件事只一处」

推荐 B（用户 17:52 补充「导入后要去第 3 页」之后，理由更强）。 换机的人在心里比较「要不要重填」的时刻，就是看到「你的班表是哪一种？」的那一刻；这时右上角有「导入」，他会点。 放到页面底部，他已经在做题了，不会回头找——而且「底部一行」暗示「填完这里再往下」，与「跳去第 3 页」正好相反。
第 2、3 页不放入口：真到第 3 页才想导入的人，设置页里还有同一个入口，不算绝路。

点下去之后（两个方案共用）

导入备份 → 校验格式 → 确认「将覆盖当前全部设置」→ 覆盖导入 → 刷新第 2 页数据 → 跳到第 3 页开权限 → 开始使用
① 不能直接进主界面：新手机没有任何权限，跳过第 3 页等于「导入完也不响」。
② 不能继续走第 2 页：那一页会把第一个闹钟改成 07:30，覆盖导入的值。
③ 必须刷新第 2 页：它的大字用的是内存里的 hour/minute 字段（GuideActivity.java:241）， 不重新读 Prefs 就会显示 07:30，用户点「改时间」时把导入的 06:45 覆盖掉。

成本：把设置页里「选文件 → 校验 → 确认 → 落盘」抽成独立类供两处调用（约半天）， 另加「导入后刷新第 2 页 + 跳第 3 页」的衔接（小半天）。版本按规则走 1.47.0 / 123。
