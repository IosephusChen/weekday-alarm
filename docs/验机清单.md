# 真机验机清单

用于「装上之后逐项点一遍」的场景。只收**真机上才能判**的项——颜色、手感、弹出、
系统拦截、以及关机这种 Robolectric 完全没有的路径。单测覆盖得到的都不在这里。

判据一律写成「看到什么算过、看到什么算没过」，不写「验证功能正常」。

> 每次发版只验这一次改动的那几组，不用从头重跑。往下翻到对应版本那一节。

---

## v1.27.0 / 328 · 换机迁移 + 关机闹钟开关

装之前：覆盖安装，**不要先卸载**（卸载会清掉班表，也就测不出迁移）。

### 1. 关机闹钟开关（设置 → 响铃 → 关机闹钟）

- [ ] 这一行右侧有开关；没授权时它是灰的 / 关的，不是「已开启」
- [ ] 点这一行会弹系统权限框；允许之后开关自动变成开
- [ ] **关掉开关后再关机等一次**：到点不响 ← 这是开关真正生效的唯一判据
- [ ] 开着开关、关机等一次：到点响（若这行显示「这款机型不支持」，本项跳过并记下机型）
- [ ] 时钟 App 里「关机闹钟响铃」开关关着时，本 App 这条是否仍生效（记结果，不改代码）

> 失败长什么样：关掉开关后仍响 → 撤 RTC 那条没生效；开着不响 → vendor 那条路在你的
> 机型上不通，属机型限制，不是 bug。

### 2. 换机迁移

- [ ] 备份到云（设置 → 系统 → 备份），改天在新机恢复，打开 App 班表与闹钟还在
- [ ] 没有云恢复条件时：「导出配置」→ 新机「导入配置」，班表、请假标记、响铃设置都在

> 失败长什么样：新机打开是空的默认双休 07:30 → 备份没带上 sharedpref。

### 3. 设置页观感

- [ ] 「响铃」卡末尾那条关机说明在小屏上不超过三行，卡不显得头重脚轻

## v1.23.38 / 323 · 封版八条里要在真机看的

- [ ] 跨零点的夜班（如 22:00 上班、次日 06:00 下班）：次日一早仍能响
- [ ] 点「这次不响」，第二天到点照常响（不复活成「永久静音」）
- [ ] 编辑闹钟时改班表，导出再导入，班次定义与轮值都在

## v1.23.37 / 322 · 响铃时的三个动作

- [ ] 通知「停止」：点一下立即停，不留残音
- [ ] 「N 分钟后再响」：到点真的再响一次
- [ ] 设置里的「测试响铃」：能被正常结束，不卡在前台服务里
- [ ] 首页那行「正在响铃 · 停止」与悬浮横幅的停止 / 小睡同样有效

## 怎么记结果

验完把「哪几项没过 + 机型 + 系统版本」三样一起给，不用贴日志。颜色 / 间距这类
只写「哪里看着不对」，不写「应该改成 12dp」——那是我看完图再定的。
